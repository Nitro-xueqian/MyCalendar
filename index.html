校历与课程日历

中国科学技术大学本科教学日历 + 个人课程表，已合并为一个可订阅的 iCal 日历，约每天自动同步。

https://<你的GitHub用户名>.github.io/Calendar/calendar.ics

Google 日历

  1. 打开 Google 日历网页版
  2. 左侧“其他日历”旁点 +，选择“从网址添加”
  3. 粘贴上面的订阅地址，点击“添加日历”

Apple 日历 (iPhone / Mac)

  1. 点击 此处订阅（或手动添加：文件 → 新建日历订阅）
  2. 粘贴地址：webcal://<你的GitHub用户名>.github.io/Calendar/calendar.ics
  3. 按需调整同步频率，点击“订阅”

Outlook

  1. Outlook 中：文件 → 账户设置 → 账户设置
  2. 选择“Internet 日历”选项卡 → 新建
  3. 粘贴订阅地址 → 添加

更新日历

  1. 编辑 2026秋季课程/2026.md 增加或修改课程
  2. 本地运行 python build_calendar.py 重新生成
  3. 提交并推送到 GitHub，Pages 会自动重新部署（也可手动触发 Actions）
